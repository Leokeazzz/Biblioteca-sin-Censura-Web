🔧 Personalización Rápida

📞 Número de WhatsApp

Abre index.html y reemplaza:

51999999999

Con tu número (sin + ni espacios):

34666777888

Aparece en: Navbar, Hero, Pricing, Footer

📷 Logo

Reemplaza:

assets/logo.png

Con tu logo cuadrado. Recomendado:

512x512px (PNG, JPG o SVG)

🎨 Colores

Edita style.css líneas 15-25:

--primary-blue: #0D4B82
--dark-blue: #0B3E6C
--background: #081420
⚠️ IMPORTANTE: No olvides cambiar el número de WhatsApp (51999999999) por el tuyo antes de desplegar. Aparece en múltiples lugares: navbar, botones hero, pricing y footer.

📤 Desplegar en GitHub Pages

Paso 1: Crear Repositorio

Ve a github.com/new

Nombre: [tu_usuario].github.io

Tipo: Público

Este nombre es EXACTO y requerido

Paso 2: Subir Archivos

En terminal:

git init
git add .
git commit -m "Landing page"
git branch -M main
git remote add origin https://...
git push -u origin main

Ver DEPLOYMENT.md para detalles

Paso 3: Verificar

En GitHub: Settings → Pages

Branch: main

Folder: / (root)

Tu sitio estará en: https://[tu_usuario].github.io
